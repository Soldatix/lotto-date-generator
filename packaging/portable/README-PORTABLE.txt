Date Lotto Generator — Windows Portable 1.0.2 (x64)
=================================================

ENGLISH

- Extract the whole ZIP into a writable folder, e.g. Downloads or a USB drive.
- Double-click date-lotto-generator.exe. No installer or MSIX package is needed.
- Requires Windows 10/11 x64 and Microsoft Edge WebView2 Runtime. WebView2
  normally ships with Windows 10/11; install it from Microsoft if missing.
- You do not need a Store installation or Apps & Games account.
- Portable means no installer. Saved combinations and preferences still
  reside in the Windows user profile, not automatically beside this EXE.
  Microsoft Store and Portable may have separate app storage.
- Transfer combinations, Personal Keys, theme and language via Settings
  (gear icon): Export backup on the source, Import backup on the destination.
- Portable ZIP does not auto-update. Get updates from the official website
  or Soldatix GitHub Releases.
- The EXE may be unsigned even if the MSIX distributed by Microsoft Store
  is signed. Only trust files from the official publisher; do not bypass
  Windows SmartScreen for files from unknown sources.
- Verify the archive SHA-256 against the checksum published with the release.
  SHA256SUMS.txt inside the ZIP lists the EXE checksum.

HRVATSKI

- Raspakirajte cijeli ZIP u mapu u koju smijete pisati, npr. Downloads ili USB.
- Pokrenite date-lotto-generator.exe dvostrukim klikom, bez instalacije.
- Potrebni su Windows 10/11 x64 i Microsoft Edge WebView2 Runtime.
  Ako WebView2 nedostaje, instalirajte ga sa službene Microsoftove stranice.
- Za pokretanje nisu potrebni Microsoft Store ni Apps & Games račun.
- Portable znači bez instalacijskog programa. Podaci se i dalje mogu čuvati
  u Windows korisničkom profilu, ne nužno u mapi EXE datoteke.
  Store i Portable mogu imati odvojenu lokalnu pohranu.
- Prijenos kombinacija, osobnih ključeva, jezika i teme: Settings (ikona
  zupčanika) > Export backup, a zatim Import backup na drugom uređaju.
- Portable ZIP nema automatsko ažuriranje. Nove verzije preuzimajte samo
  sa službene stranice Apps & Games ili GitHub Releases.
- EXE možda nema vlastiti digitalni potpis iako je Store MSIX potpisan.
  Ne zaobilazite sigurnosna upozorenja za datoteke nepoznatog podrijetla.
- SHA-256 ZIP-a usporedite s vrijednošću uz službenu objavu.
  SHA256SUMS.txt sadrži i kontrolni zbroj EXE datoteke.
